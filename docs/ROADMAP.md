# ROADMAP

## Next (before design)
- Стабилизация багов текущего MVP-потока (templates → start → workout → finish → history).
- Мелкие UX-правки: тексты ошибок, состояния кнопок, предсказуемость навигации, аккуратные edge-case сценарии.

## Design phase
- Введение design tokens как базового слоя визуальной системы.
- Поддержка theming и **переключаемой цветовой палитры через настройки** (CSS variables).
- Выделение и стандартизация UI-компонентов для единообразного интерфейса.

## Functional extensions
- Строгая валидация данных подходов по `exercise.type` на уровне контрактов и UI.
- Опциональный autosave для template editor (только после явного продуктового решения).
- Аналитика и прогресс: агрегаты, метрики, визуализации.

## Long-term
- Тренеры и роли для совместной работы.
- Социальные механики (друзья, обмен прогрессом, вовлечение).
- AI-подсказки по тренировкам и адаптации нагрузки.
