# UI FLOWS (MVP)

## Каркас приложения (routing/providers/http client/initData)
- Routing: React Router, маршруты объявлены в `src/app/router.tsx`.
- Providers: React Query (QueryClientProvider), Telegram WebApp SDK и тема Telegram подключаются в app-layer.
- HTTP client: только `src/shared/api/http.ts`, базовый URL из `import.meta.env.VITE_API_BASE_URL`.
- InitData: читается через `src/shared/lib/telegram.ts`, заголовок `X-Tg-Init-Data` добавляется автоматически.

## Список экранов MVP
- `/templates`
- `/templates/new`
- `/templates/:id/edit`
- `/start`
- `/workouts/:id`
- `/workouts`

## Переходы между экранами
- `/templates` → `/templates/new` (создать шаблон).
- `/templates` → `/templates/:id/edit` (редактировать шаблон).
- `/templates` → `/start` (перейти к запуску тренировки).
- `/templates` → `/workouts` (перейти к истории тренировок).
- `/start` → `/workouts/:id` (после старта тренировки).
- `/start` → `/workouts` (перейти к истории тренировок).
- `/workouts/:id` → `/workouts` (завершить тренировку и вернуться в историю).
- `/workouts` → `/workouts/:id` (открыть тренировку из списка).
- Любой экран → `/templates` (через навигацию/BackButton).

## Общие состояния
- Loading: skeleton/спиннеры, блокировка действий, предотвращение повторных запросов.
- Empty: объясняющий текст + CTA (создать шаблон/начать тренировку).
- Error: человекочитаемое сообщение + retry.
- Success: краткое подтверждение (toast/inline) и актуализация списка.

## Экран: /templates
**Цель:** список шаблонов, быстрые действия (создать/удалить/перейти к редактированию).

**Ввод пользователя:**
- Нажать «Создать».
- Нажать «Удалить» у шаблона.
- Нажать «Редактировать» у шаблона.
- Нажать «К запуску тренировки».

**Основные компоненты:**
- Список карточек шаблонов.
- Кнопка «Создать шаблон».
- Ссылка/кнопка перехода на экран запуска тренировки.
- Пустое состояние.

**API endpoints:**
- `GET /api/templates` — список.
- `DELETE /api/templates/{id}` — удалить.

## Экран: /templates/new
**Цель:** создать шаблон тренировки.

**Ввод пользователя:**
- Название шаблона.
- Добавление упражнений и подходов.
- Сохранить.

**Основные компоненты:**
- Форма (react-hook-form + zod).
- Секция упражнений с наборами.
- Кнопка «Сохранить».

**API endpoints:**
- `POST /api/templates` — создать шаблон.

## Экран: /templates/:id/edit
**Цель:** редактировать существующий шаблон.

**Ввод пользователя:**
- Изменить название.
- Добавить/удалить упражнения и подходы.
- Сохранить.

**Основные компоненты:**
- Форма редактирования.
- Секция упражнений.
- Кнопки «Сохранить»/«Удалить».

**API endpoints:**
- `GET /api/templates/{id}` — загрузить данные.
- `PUT /api/templates/{id}` — обновить.
- `DELETE /api/templates/{id}` — удалить.

## Экран: /start
**Цель:** старт тренировки (с шаблоном или без).

**Ввод пользователя:**
- Выбор шаблона и запуск по нему.
- Запуск тренировки без шаблона.

**Основные компоненты:**
- Список шаблонов.
- Кнопки «Начать по шаблону» и «Начать без шаблона».
- Empty state с переходом к созданию шаблонов.

**API endpoints:**
- `GET /api/templates` — список шаблонов.
- `POST /api/workouts/start` — запуск тренировки.

## Экран: /workouts/:id
**Цель:** ведение текущей тренировки (упражнения/подходы, ввод reps/weight/duration).

**Ввод пользователя:**
- Добавить упражнение.
- Добавить/удалить подход.
- Ввести значения подхода.
- Завершить тренировку.

**Основные компоненты:**
- Список упражнений.
- Карточки подходов с инпутами.
- Подсказки last-max рядом с упражнением.
- Кнопки «Добавить упражнение/подход».
- Кнопка «Закончить тренировку» и статус «Завершена» для read-only режима.

**API endpoints:**
- `GET /api/workouts/{workoutId}` — загрузить тренировку.
- `POST /api/workouts/{workoutId}/exercises` — добавить упражнение.
- `DELETE /api/workouts/{workoutId}/exercises/{workoutExerciseId}` — удалить упражнение.
- `POST /api/workouts/{workoutId}/exercises/{workoutExerciseId}/sets` — добавить подход.
- `PATCH /api/workouts/{workoutId}/sets/{setEntryId}` — обновить подход (autosave по blur/debounce).
- `DELETE /api/workouts/{workoutId}/exercises/{workoutExerciseId}/sets/{setEntryId}` — удалить подход.
- `POST /api/workouts/{workoutId}/finish` — завершить тренировку.
- `GET /api/exercises/{exerciseId}/last-max` — last-max подсказки.

**Примечание:**
- Значения reps/weight/duration сохраняются автоматически при вводе (blur и debounce 600ms).
- После завершения тренировки UI переходит в read-only и возвращает пользователя в историю.
- Валидация перед завершением: подход валиден при заполненных (reps + weight) или duration; пустые поля подсвечиваются. В будущем поля будут зависеть от типа упражнения.

## Экран: /workouts
**Цель:** список тренировок пользователя и переход к деталям.

**Ввод пользователя:**
- Открыть тренировку.

**Основные компоненты:**
- Список тренировок (история/активные).
- Пустое состояние.

**API endpoints:**
- `GET /api/workouts` — список тренировок.
