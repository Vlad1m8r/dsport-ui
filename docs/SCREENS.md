# SCREENS

## Home (`/`)
- Профиль пользователя: ник и аватар из Telegram (`initDataUnsafe.user`).
- Fallback: при отсутствии данных показывается пустой аватар и имя `пользователь`.
- Основной CTA:
  - «Продолжить тренировку» при наличии активной тренировки `IN_PROGRESS`.
  - «Начать тренировку» при отсутствии активной тренировки.
- Быстрые переходы: «Шаблоны» (`/templates`) и «История» (`/workouts`).
- Плейсхолдер: блок «Календарь (скоро)».
- Единый хедер приложения: кнопки «Назад» и «Главная».

## Templates (`/templates`)
- Список шаблонов тренировок с действиями «Изменить» и «Удалить».
- Кнопка «Создать шаблон» сразу создаёт шаблон на backend (`POST /api/templates`) с дефолтным именем `Новый шаблон` и переводит в редактор `/templates/:id/edit`.
- Вторичный CTA по активной тренировке:
  - «Продолжить начатую» при наличии `IN_PROGRESS` → `/workouts/:id`.
  - «Начать тренировку» при отсутствии активной тренировки → `/start`.
- Ссылка «История» ведёт на `/workouts`.
