# SCREENS

## Home (`/`)
- Профиль пользователя: имя и аватар из Telegram (`initDataUnsafe.user`) с fallback на имя `пользователь` и инициалы.
- В `UserHeader` используются:
  - крупный заголовок пользователя слева;
  - блок controls справа: `IconButton` для переключения темы + аватар;
  - переключение темы через `html[data-mode]` (`light`/`dark`).
- Основной CTA:
  - «Продолжить» при наличии активной тренировки `IN_PROGRESS`;
  - «Начать тренировку» при отсутствии активной тренировки.
- Быстрые переходы: «Шаблоны» (`/templates`) и «История» (`/workouts`) в виде карточек-action tiles.
- Слайдер Home:
  - первый слайд — календарь текущего месяца;
  - остальные слайды — служебные «В разработке»;
  - поддерживается drag за пальцем (pointer/touch move), сдвиг трека через CSS-переменную `--drag-x`, отключение transition во время перетаскивания;
  - на крайних слайдах применяется «сопротивление» свайпа.
- Нижняя навигация (`FooterNav`) оформлена как плавающий dock/капсула:
  - учитывает `--safe-bottom`;
  - использует glassmorphism;
  - активная кнопка «Главная» выделяется акцентной пилюлей.

## Templates (`/templates`)
- Список шаблонов тренировок с действиями «Изменить» и «Удалить».
- Кнопка «Создать шаблон» сразу создаёт шаблон на backend (`POST /api/templates`) с дефолтным именем `Новый шаблон` и переводит в редактор `/templates/:id/edit`.
- Вторичный CTA по активной тренировке:
  - «Продолжить начатую» при наличии `IN_PROGRESS` → `/workouts/:id`.
  - «Начать тренировку» при отсутствии активной тренировки → `/start`.
- Ссылка «История» ведёт на `/workouts`.

## Workouts history (`/workouts`)
- Экран истории запрашивает только завершённые тренировки: `GET /api/workouts?status=FINISHED`.
- Список не показывает `IN_PROGRESS` сессии: отображаются только элементы со статусом `FINISHED`.
- Доступен переход в детали тренировки по нажатию на элемент списка.
- Используется общий `AppHeader` с явными кнопками навигации «Назад» (`navigate(-1)`) и «Главная» (`navigate("/")`).

## WorkoutPage (`/workouts/:id`)
- Экран имеет два режима:
  - `editable` для активной тренировки (`finishedAt == null`): доступны CTA «Добавить упражнение», кнопки add/remove set/exercise и блоки `last-max`.
  - `read-only` для завершённой тренировки (`finishedAt != null`): скрываются CTA/кнопки редактирования и `last-max`, инпуты остаются disabled.
- В верхней части экрана для завершённой тренировки показывается статус «Завершена» (с временем, если доступно).
