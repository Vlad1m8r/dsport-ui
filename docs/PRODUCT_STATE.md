# PRODUCT STATE (MVP)

## Purpose MVP
MVP решает базовый сценарий силовой/функциональной тренировки в Telegram Mini App: пользователь собирает шаблоны, запускает тренировку, ведёт подходы и завершает с сохранением результата в истории.

Ключевая цель текущего этапа — зафиксировать рабочий end-to-end поток без визуальной полировки: от подготовки шаблона до read-only просмотра завершённой сессии.

## What is implemented
- **Templates (list/create/edit/delete)**
  - Список шаблонов, удаление, отдельный экран создания, переход в экран редактирования.
- **Template editor with draft (client-only, persisted)**
  - Редактор работает через локальный draft, который хранится в `sessionStorage`.
  - Изменения не уходят на backend до явного нажатия «Сохранить».
- **Exercise catalog + picker (bulk fetch, frontend filtering)**
  - Общий ExercisePicker загружает каталог упражнений и фильтрует на фронте (поиск/фильтры).
- **Start workout (from template / empty)**
  - Экран запуска поддерживает старт по выбранному шаблону или пустой тренировки.
- **Active workout editing**
  - В активной тренировке можно добавлять/удалять упражнения и подходы, редактировать поля подходов по типу упражнения.
- **Autosave sets (PATCH on blur/debounce)**
  - Подходы сохраняются автоматически: при `blur` и через debounce.
- **Finish workout + read-only mode**
  - Завершение тренировки фиксируется через API, после чего экран блокируется в read-only.
- **Workouts history**
  - Отдельный экран истории тренировок с открытием конкретной сессии.

## What is NOT implemented yet
- Дизайн и визуальная полировка интерфейса.
- Настройки пользователя.
- Смена цветовой темы пользователем.
- Тренеры / друзья / социальные связи.
- Аналитика и графики прогресса.
